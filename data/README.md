# Data

This directory contains the datasets used by the AI Workload Forecast and Planning Assistant.

## Dataset Source

The project uses the Gryzzly time-tracking dataset as the initial historical workload data source.

The raw dataset is intentionally excluded from GitHub because of its large size.

## Directory Structure

- `raw/` — Original downloaded datasets
- `processed/` — Cleaned and transformed datasets generated by the data pipeline

The raw dataset should be downloaded locally before running the data processing pipeline.
