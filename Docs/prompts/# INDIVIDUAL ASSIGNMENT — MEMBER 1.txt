## 6. Agentic AI assistant — your main advanced component

Build an Agentic AI layer that can understand workforce-related questions and use controlled tools to answer them.

Example manager questions:
- Which employees may be overloaded next week?
- Which team has available capacity?
- Which employees have the skills required for a particular task?
- Why is a project at risk?
- Suggest a better distribution of tasks.
- Compare current and predicted workload.
- Explain why an employee was recommended.

### Required agent workflow

1. Receive a user question.
2. Identify the user's role and permissions.
3. Understand the intent.
4. Decide which tool or tools are required.
5. Call the authorized backend service or module.
6. Validate and interpret returned results.
7. Produce a grounded explanation.
8. Offer a recommendation when appropriate.
9. Request manager approval before consequential changes.
10. Execute only approved actions.
11. Record the action and its result in an audit trail.

### Tools the agent should eventually use

- Employee lookup
- Team lookup
- Project lookup
- Task lookup
- Workload analytics
- Workload forecast
- Capacity analysis
- Risk analysis
- Resource optimization
- Approval submission
- Approved task reassignment

These must be actual controlled functions or API calls, not fabricated tool results.

### Agent safety and permissions

- An employee can ask about their own tasks, workload, deadlines and availability.
- An employee must not access other employees' private information.
- A manager can query authorized company workforce information.
- The agent must not bypass backend authorization.
- The agent must not execute a task reassignment just because a user asks it to recommend one.
- Approval must be recorded before a consequential action.
- Every approved action must be validated again at execution time.
- Store recommendation, approval, execution status and audit details.
- Never expose database passwords, secrets or private records in AI responses.

### Conversation examples to support

Manager:
"Which employees can take on another task next week?"

Agent:
- Retrieves next week's forecast.
- Retrieves available capacity.
- Identifies suitable employees.
- Explains the selection.
- Provides recommendations.

Manager:
"Assign Task 104 to Employee 205."

Agent:
- Checks permissions and task details.
- Checks employee skills and capacity.
- Presents the proposed assignment.
- Requests approval.
- Executes only after approval.
- Confirms the actual result.

Employee:
"What should I work on today?"

Agent:
- Retrieves only that employee's assigned tasks and deadlines.
- Explains priorities based on available task information.
