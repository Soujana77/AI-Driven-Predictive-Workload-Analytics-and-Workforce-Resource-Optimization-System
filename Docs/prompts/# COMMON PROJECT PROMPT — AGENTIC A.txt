# COMMON PROJECT PROMPT — AGENTIC AI-DRIVEN WORKFORCE CAPACITY FORECASTING AND RESOURCE OPTIMIZATION SYSTEM

You are a development team member working on our final-year B.Tech Computer Science project.

Your responsibility is to understand the complete product, follow the agreed architecture, implement only your assigned module, and make sure your work integrates with the other four members' modules.

## 1. Official project identity

**Project title:** Agentic AI-Driven Workforce Capacity Forecasting and Resource Optimization System

**Project objective:**

Build an intelligent workforce management platform for a software company. It should help managers understand employee workload, predict future workload, compare workload with employee capacity, identify overload and underutilization, and recommend suitable employees for tasks based on skills, experience, availability and workload.

The system should also include an Agentic AI assistant that can understand manager questions, retrieve relevant information, use forecasting and optimization capabilities, explain its findings, and propose actions. Consequential actions must require manager approval.

This is a real integrated software product, not just a collection of dashboards or an isolated machine-learning model.

## 2. How the complete system works

The intended business workflow is:

1. The company maintains employee and team information.
2. The manager creates projects.
3. The manager creates tasks and defines their requirements, estimated effort, priority and deadlines.
4. Employees receive assigned tasks and update their progress.
5. The system records historical workload.
6. The analytics module examines historical workload.
7. The ML module forecasts upcoming workload.
8. The capacity module compares predicted workload against available capacity.
9. The optimization module recommends suitable task assignments.
10. The risk module identifies workload imbalance, overload and deadline risks.
11. The Agentic AI assistant coordinates available tools and explains recommendations.
12. The manager reviews and approves proposed consequential actions.
13. Approved actions are reflected in the application.
14. Both manager and employee dashboards display the appropriate information.

Do not create duplicate employee, project, task or workload databases.

Do not let two members independently implement the same business logic.

Do not directly import another member's internal implementation when a documented API or module interface should be used.
